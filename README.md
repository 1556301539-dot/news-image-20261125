## What it is

`main.py` (Python 3.13, stdlib + Pillow only) generates a deterministic
1024×1024 newspaper front page — **"THE WORLD IN ONE PAGE"** — summarising
real world news from Wednesday 25 November 2026:

- **Lead:** Hormuz in flames — MQ-9 drone downed, ~25 tankers hit,
  Strait of Hormuz traffic down 40%, Brent below $90.
- **Space:** Shenzhou-24 launches from Jiuquan with the first Pakistani
  astronaut, Muhammad Zeeshan Ali, aboard Tiangong.
- **Courts:** Huawei convicted in Brooklyn on 10 of 12 counts.
- **Map:** a simplified world map with dots marking the day's stories.
- **Around the world:** Europe, Africa, Americas, Asia-Pacific,
  Middle East, Oceania briefs, plus an "In Brief" ticker.
- All headlines were researched from real reporting on 25 Nov 2026 —
  see [SOURCES.md](SOURCES.md). No story was fabricated.

## How to run

```bash
python3 main.py
```

- Writes `/output/entry.png` (the scoring path) and `./output/entry.png`.
- No network, no randomness, no timestamps. Running twice produces
  byte-identical output (same SHA-256).
- Requires Pillow (`pip install Pillow`). Fonts: DejaVu / Liberation
  (bundled on most Linux systems), with a Pillow-default fallback.
